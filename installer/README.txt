УКРАЇНІЗАТОР SUNLESS SEA: ZUBMARINER
====================================

Неофіційний український переклад. Сюжет, описи, підказки, інтерфейс.
Протестовано на macOS, версія гри V3.0.0.31.


ЯК ВСТАНОВИТИ (macOS)
---------------------
1. Запусти гру, почни нову гру, вийди з неї. Це потрібно один раз,
   щоб гра створила свою теку з текстом.
2. Закрий гру і Steam.
3. Клікни правою кнопкою на «Встановити.command» → Відкрити →
   у віконці ще раз Відкрити.
   (Просто подвійний клік macOS заблокує: файл скачаний з інтернету.)
4. Чекай. Перший запуск сам донесе все, що йому треба:
   дві пітонівські бібліотеки, а якщо в системі немає Mono –
   ще й Homebrew з Mono (це разово, близько гігабайта, і Термінал
   спитає пароль від мака). Від Mono можна відмовитись: тоді
   перекладеться все, крім меню й суднового журналу.
5. Запусти гру і почни НОВУ ГРУ.

Відкотити все: «Відкотити.command» так само.


ЧОМУ ТРЕБА НОВА ГРА
-------------------
Sunless Sea зберігає описи якостей усередині файлу збереження.
Старий сейв тягтиме англійський текст незалежно від перекладу.


ЯКЩО ЩОСЬ ПІШЛО НЕ ТАК
----------------------
Не знайшло теку гри або теку з текстом – запусти з підказкою:

    python3 install.py --game "<шлях до SunlessSea>"
    python3 install.py --data "<шлях до теки з контентом>"

Тека з контентом:
  macOS    ~/Library/Application Support/com.failbettergames.sunlesssea
  Windows  %USERPROFILE%\AppData\LocalLow\Failbetter Games\Sunless Sea

Обережно: поруч може лежати тека «unity.Failbetter Games.Sunless Sea».
Гра її не читає, правити там нема сенсу.


WINDOWS І LINUX
---------------
Інсталятор кросплатформний, але його там ніхто не перевіряв.
Потрібно: Python 3.8+, потім

    pip3 install UnityPy fonttools
    python3 install.py

На Windows Mono не потрібен зовсім, на Linux – потрібен
(sudo apt install mono-runtime). Решта перекладу встановиться в
будь-якому разі.


ЩО САМЕ ЗМІНЮЄТЬСЯ
------------------
- контентні JSON у теці користувача: сюжет, описи, підказки
- шрифти в resources.assets: вшиті латинські замінюються на системні
  кириличні, інакше українські літери не намалюються
- підписи інтерфейсу в resources.assets
- підписи інтерфейсу в Managed/Sunless.Game.dll

Кожен крок робить бекап поруч із оригіналом.


ЩО ЛИШАЄТЬСЯ АНГЛІЙСЬКОЮ
------------------------
Кілька написів: Continue, Yes, No, Hull, Hold, Use, Forward і назви
дій у прив'язках клавіш. Гра використовує ці самі рядки як внутрішні
ключі пошуку кнопок. Переклад зламав би керування.

Назви місяців у датах приходять із системної локалі, не з гри.


ЯКЩО STEAM ОНОВИТЬ ГРУ
----------------------
Перевірка цілісності файлів поверне оригінальні resources.assets і
Sunless.Game.dll. Текст у теці користувача вціліє, інтерфейс і шрифти
ні. Лікується повторним встановленням.


ПРО ПЕРЕКЛАД
------------
Зроблено мовною моделлю під ручним доглядом: узгоджений глосарій
власних назв, звірка спірних місць з оригіналом, окремий прохід на
милозвучність імен. Професійного редактора не було.

Файли гри тут не роздаються: інсталятор патчить вашу власну копію.
Український текст у data/ прив'язаний до хешів оригінальних рядків,
англійського тексту Failbetter в архіві немає.
